## Overview
This repository contains a **Next.js (App Router)** application that acts as a personal knowledge base or "Field Notes" system. The application serves Markdown-based notes located in the `content` directory, parsing them with frontmatter to display metadata such as titles, descriptions, tags, and dates.

## Tech Stack
- **Framework**: [Next.js 16.2.6](https://nextjs.org) (React 19)
- **Styling**: Tailwind CSS v4.3.3
- **UI Components**: [shadcn/ui](https://ui.shadcn.com/) (using `@base-ui/react`, `lucide-react`, `class-variance-authority`, `clsx`, `tailwind-merge`)
- **Content Processing**:
  - `gray-matter`: For parsing YAML frontmatter in Markdown notes.
  - `react-markdown`, `rehype-slug`, `remark-gfm`: For rendering Markdown to React components with support for GitHub Flavored Markdown and heading slugs.
- **Other Utilities**: `@vercel/analytics` for usage tracking, `next-themes` for dark/light mode toggling.

## Architecture & Folder Structure

### `app/` (Next.js App Router)
- **`layout.tsx`**: Defines the root HTML and body, including the global navigation and search overlay (Cmd+K).
- **`page.tsx`**: The main index page. It fetches all notes and displays them as a list of cards showing the title, date, excerpt, and tags.
- **`notes/`**: A dynamic route (likely `app/notes/[slug]/page.tsx`) responsible for rendering individual Markdown notes.
- **`tags/`**: A dynamic route (likely `app/tags/[tag]/page.tsx`) responsible for rendering lists of notes filtered by specific tags.

### `lib/` (Core Logic)
- **`notes.ts`**: The primary data access layer for content.
  - Reads `.md` files from the `content/` directory using Node.js `fs`.
  - Exposes functions like `getAllNotes()`, `getNote(slug)`, `getAllTags()`, and `getNotesByTag(tag)`.
  - Parses out frontmatter and extracts headings to build table of contents or anchor links using `slugifyHeading`.
  - Strips Markdown down to plain text (`toPlainText`) to build a localized `searchText` field used in the Cmd+K search interface.

### `content/` (Data)
The actual markdown notes. Current examples include:
- `coffee-brewing.md`
- `getting-started.md`
- `nextjs-notes.md`
- `project-ideas.md`
- `reading-list.md`

### `components/`
- **`ui/`**: Base reusable UI components generated by shadcn/ui (`badge.tsx`, `button.tsx`, `dialog.tsx`, `input.tsx`, `scroll-area.tsx`, `separator.tsx`, `sheet.tsx`).
- It likely also includes a global `SearchDialog` or `CommandMenu` component handling the `⌘K` global search functionality mentioned on the homepage.
