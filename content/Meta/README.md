# Notes

A practical revision notebook for JavaScript, TypeScript, React, Prisma, browser tooling, commands, and backend fundamentals.

## Start Here

- [JavaScript](javascript.md): language fundamentals, browser APIs, Node basics, production guidance, commands, resources, and interview questions.
- [TypeScript](typescript.md): strict-mode typing, narrowing, generics, runtime validation cautions, Prisma examples, production practices, and interview questions.
- [React](react.md): components, JSX, state, forms, effects, Hooks, context, reducers, TypeScript, styling, routing/data loading, testing, production architecture, accessibility, and security.
- [Frontend Design](frontend-design.md): CSS foundations, responsive layout, typography, spacing, color, accessibility, design tokens, Tailwind, headless UI, component libraries, icons, animation, charts, tables, and drag/drop.
- [Color Guide](color.md): UI color roles, contrast, palette structure, brand and semantic colors, data colors, dark mode, CSS tokens, Tailwind tokens, and shadcn/ui theming.
- [Tailwind CSS](tailwind.md): setup, utility classes, responsive design, theme tokens, dark mode, class composition, forms, dashboards, mistakes, and production checks.
- [shadcn/ui](shadcn.md): setup, CLI workflow, `components.json`, component anatomy, theming, Tailwind v4 notes, forms, customization, updates, and accessibility checks.
- [Frontend Testing](frontend-testing.md): Vitest, Testing Library, MSW, Playwright, Storybook, accessibility checks, visual regression, CI strategy, and testing practice path.
- [UI Patterns](ui-patterns.md): practical cookbook for forms, settings pages, dashboards, tables, filters, empty states, loading, errors, dialogs, command menus, uploads, navigation, toasts, and destructive actions.
- [State Management](state-management.md): React built-ins, server state, TanStack Query, Zustand, Redux Toolkit, Jotai, Recoil status, URL state, form state, persistence, and choosing the right tool.
- [Next.js](nextjs.md): App Router, layouts, Server and Client Components, data fetching, caching, Server Functions, Route Handlers, Prisma boundaries, security, testing, and deployment.
- [Next.js Auth](nextjs-auth.md): authentication, sessions, cookies, Auth.js, credentials, OAuth, authorization, CSRF, XSS, multi-tenant roles, rate limiting, and auth testing.
- [Prisma](Prisma.md): schema basics, Prisma Client, CRUD, relations, migrations, seeding, transactions, production database practices, commands, and exercises.
- [Full-Stack Libraries](libraries.md): Zod, bcrypt, JWTs, fetch/Axios, security middleware, logging, utility libraries, testing tools, and how they fit together.
- [Browser DevTools](browser-tools.md): Elements, Console, Sources, Network, storage, performance, security, and production debugging workflows.
- [Commands and Shortcuts](command.md): terminal, Git, Node/npm, Prisma, VS Code shortcuts, and project checks with safety labels.
